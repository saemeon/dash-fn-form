    dash-fn-form¶

    Headless engine for dash-interact. Introspects a type-hinted Python callable and builds a reactive Dash form panel.

    Most users should install dash-interact instead — it includes this package and adds the page API.

    Installation¶

    pip install dash-fn-form

    Usage¶

    from dash import Dash, html
from dash_fn_form import build_fn_panel

app = Dash(__name__)

def sine_wave(amplitude: float = 1.0, frequency: float = 2.0):
    import numpy as np, plotly.graph_objects as go
    x = np.linspace(0, 6 * np.pi, 600)
    return go.Figure(go.Scatter(x=x, y=amplitude * np.sin(frequency * x)))

panel = build_fn_panel(sine_wave)

app.layout = html.Div([panel])
app.run(debug=True)

    build_fn_panel returns an html.Div containing the form and output area — wire it into any layout.

    API¶

    build_fn_panel¶

    Build and return a self-contained interactive panel.

    Registers Dash callbacks and returns an html.Div. Has no knowledge of pages; the caller is responsible for placing the panel in a layout.

    PARAMETER DESCRIPTION
    fn

    Callable whose parameters define the form fields.

    TYPE: Callable

    _id

    Explicit component-ID namespace. Defaults to fn.__name__. Pass a unique string when two panels wrap functions with the same name to prevent Dash component-ID collisions.

    TYPE: str | None DEFAULT: None

    _manual

    False — live update on every field change. True — Apply button; callback fires on click only.

    TYPE: bool DEFAULT: False

    _loading

    Wrap the output area in dcc.Loading (default True).

    TYPE: bool DEFAULT: True

    _render

    Optional converter applied to fn's return value before display.

    TYPE: Callable[[Any], Any] | None DEFAULT: None

    _cache

    Cache function call results by input values (default False). Skips re-calling fn when the same field values are submitted again.

    TYPE: bool DEFAULT: False

    _cache_maxsize

    Maximum number of cached results (LRU eviction). Default 128.

    TYPE: int DEFAULT: 128

    **kwargs

    Per-field shorthands forwarded to :class:FnForm.

    TYPE: Any DEFAULT: {}

    FnForm¶

    Bases: Form

    call ¶

    call(values)

    Validate values and call the wrapped function.

    Returns (result, errors). If validation fails, result is None and errors maps field names to error messages. On success, errors is {}.

    Example::

    @app.callback(
    Output("result", "children"),
    *cfg.validation_outputs,
    Input("apply", "n_clicks"),
    *cfg.states,
)
def on_apply(_n, *values):
    result, errors = cfg.call(values)
    if errors:
        return dash.no_update, *cfg.invalid_outputs(errors)
    return str(result), *cfg.invalid_outputs({})

    call_named ¶

    call_named(**raw)

    Like :meth:call but accepts field values as keyword arguments.

    Designed for use with :attr:named_states and Dash's flexible inputs=dict(...) callback signature, where field values arrive as named kwargs rather than a positional tuple::

    @app.callback(
    Output("result", "children"),
    inputs=dict(n=Input("apply", "n_clicks"), **cfg.named_states),
)
def on_apply(n, **values):
    result, errors = cfg.call_named(**values)
    return str(result) if not errors else str(errors)

    Field¶

    Per-field configuration for :class:~dash_interact.FnForm.

    Can be supplied in three ways (highest priority wins):

    1. In-signature via Annotated[T, Field(...)] — for functions you own.
    2. External via keyword argument on :class:~dash_interact.FnForm — for functions you don't own.
    3. Type-level _styles / _class_names dicts on :class:~dash_interact.FnForm fill in any visual properties not set by the above.

    A :class:FieldHook instance may also be passed directly as a kwarg and is treated as Field(hook=hook).

    class_name class-attribute instance-attribute ¶

    class_name = ''

    CSS class applied to the component.

    col_span class-attribute instance-attribute ¶

    col_span = 1

    Column span in a multi-column grid (see _cols on :func:build_config).

    component class-attribute instance-attribute ¶

    component = None

    Replace the auto-generated component entirely. id is set internally.

    component_prop class-attribute instance-attribute ¶

    component_prop = 'value'

    Property to read back from a custom component (default: "value").

    debounce class-attribute instance-attribute ¶

    debounce = None

    Control debounce on dcc.Input / dcc.Textarea fields.

    • None (default) — use the type default (True for all text and number inputs).
    • False — update on every keystroke (useful for live search/filter).
    • True — force debounce even if the type default would be False.

    Has no effect on bool, date, datetime, literal, or enum fields, which don't use debounce.

    default class-attribute instance-attribute ¶

    default = None

    Default value for the field.

    When set, takes precedence over the callable's own parameter default. This allows reusing existing functions while overriding their defaults via field_specs — analogous to functools.partial::

    capture_graph(
    graph,
    renderer=my_renderer,               # has title: str = ""
    field_specs={"title": Field(default="Q4 Results")},  # wins
)

    Also used in :class:~dash_interact.Form declarative subclasses::

    class MyForm(Form):
    dpi: int = Field(min=72, max=300, default=150)

    description class-attribute instance-attribute ¶

    description = None

    Help text rendered below the component.

    ge = field(default=None, repr=False)

    Alias for min (greater-than-or-equal). Ignored if min is set.

    gt class-attribute instance-attribute ¶

    gt = field(default=None, repr=False)

    Alias for min (greater-than, exclusive semantics not enforced by widget). Ignored if min is set.

    hook class-attribute instance-attribute ¶

    hook = None

    Runtime hook that derives the field's default from Dash state.

    label class-attribute instance-attribute ¶

    label = None

    Override the auto-generated label (default: param name in title case).

    le class-attribute instance-attribute ¶

    le = field(default=None, repr=False)

    Alias for max (less-than-or-equal). Ignored if max is set.

    lt class-attribute instance-attribute ¶

    lt = field(default=None, repr=False)

    Alias for max (less-than, exclusive semantics not enforced by widget). Ignored if max is set.

    max class-attribute instance-attribute ¶

    max = None

    Maximum value (inclusive). Only applied to int / float fields.

    max_length class-attribute instance-attribute ¶

    max_length = None

    Maximum length. For str / path: character count. For list / tuple: item count.

    min class-attribute instance-attribute ¶

    min = None

    Minimum value (inclusive). Only applied to int / float fields.

    min_length class-attribute instance-attribute ¶

    min_length = None

    Minimum length. For str / path: character count. For list / tuple: item count.

    multiple_of class-attribute instance-attribute ¶

    multiple_of = field(default=None, repr=False)

    Alias for step. Ignored if step is set.

    pattern class-attribute instance-attribute ¶

    pattern = None

    Regex the value must fully match. Only applied to str / path fields.

    persist class-attribute instance-attribute ¶

    persist = False

    Persist the field value across page reloads using the browser's session storage.

    When True, the generated component is rendered with persistence=True, persistence_type="session" so the browser remembers the last value even after a full page refresh. Set to False (default) to keep the component stateless (always loads with the default value).

    Equivalent to wrapping every field manually in a dcc.Store — useful for sliders or dropdowns whose position the user adjusts frequently.

    step class-attribute instance-attribute ¶

    step = None

    Step size. Only applied to int / float fields.

    style class-attribute instance-attribute ¶

    style = None

    CSS dict applied to the component (not the wrapper div).

    validator class-attribute instance-attribute ¶

    validator = None

    Custom validator called with the coerced value after type checking.

    Return a human-readable error string on failure, None on success.

    Example::

    Field(validator=lambda v: "Must be positive" if v <= 0 else None)
Field(validator=lambda v: None if "@" in v else "Not a valid email")

    Can also be supplied as a bare callable in Annotated metadata::

    def positive(v): return "Must be > 0" if v <= 0 else None

def fn(dpi: Annotated[int, positive] = 150): ...

    visible class-attribute instance-attribute ¶

    visible = None

    Conditional visibility rule: ("other_field", "==", value).

    widget class-attribute instance-attribute ¶

    widget = None

    Select an alternative widget for supported types.

    • "slider" — render a dcc.Slider (or dmc.Slider) instead of a number input. Requires min and max to be set.

    FieldHook¶

    Base class for field hooks.

    Subclass to define fields whose default value and/or submitted value are derived from runtime Dash state rather than a static default.

    Override :meth:required_states to declare which Dash State objects your hook needs. Their values are passed positionally to :meth:get_default and :meth:transform.

    get_default ¶

    get_default(*state_values)

    Compute the initial field value from resolved state values.

    required_states ¶

    required_states()

    Dash State objects this hook needs at runtime.

    transform ¶

    transform(value, *state_values)

    Transform the user-submitted value before it reaches the renderer.

    register_renderer¶

    Register a custom renderer for a Python type.

    The renderer is called with the return value of the function whenever interact() produces a result of the registered type (or a subclass). This avoids passing _render= on every interact() call.

    Analogous to matplotlib's unit converter registry — register once at app startup, applies everywhere.

    Later registrations for the same type overwrite earlier ones. For subclass disambiguation, register the more-specific type after the base type; the registry is checked in insertion order and the first isinstance match wins.

    Example::

    import pandas as pd
from dash import dash_table
from dash_fn_form import register_renderer

register_renderer(
    pd.DataFrame,
    lambda df: dash_table.DataTable(
        data=df.to_dict("records"),
        columns=[{"name": c, "id": c} for c in df.columns],
    ),
)

# all interact() calls that return a DataFrame now use this renderer
panel = interact(get_data)
